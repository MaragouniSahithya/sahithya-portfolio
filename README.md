# Sahithya Portfolio

A modern developer portfolio built with **Next.js** to showcase my skills, projects, and contact information.

## 🌐 Live Website

https://sahithya-portfolio-five.vercel.app

## 📌 About This Project

This repository contains the source code for my personal developer portfolio.
The portfolio highlights my work, technical skills, and selected projects in a clean and responsive interface.

## 🛠️ Tech Stack

* Next.js
* React.js
* JavaScript
* HTML5
* CSS3

## 🚀 Features

* Modern responsive UI
* Projects showcase section
* Skills and technologies section
* Contact form
* Smooth animations

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/MaragouniSahithya/sahithya-portfolio.git
```

Go to the project folder:

```bash
cd sahithya-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```
